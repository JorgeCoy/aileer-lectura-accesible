# aLeer - Entrenador de Lectura Inteligente 🚀

**aLeer** es una aplicación web avanzada que revoluciona el entrenamiento de lectura rápida mediante técnicas científicas, inteligencia artificial y un enfoque centrado en el usuario. Diseñada para potenciar tu velocidad de lectura, comprensión y salud visual.

## ✨ Características Principales

### 📖 Entrada de Contenido Inteligente
*   **Texto Manual**: Pega cualquier contenido y comienza inmediatamente
*   **PDF Avanzado**: Procesamiento inteligente con OCR integrado
    *   **Extracción automática** de texto desde imágenes escaneadas
    *   **Marcadores inteligentes** y notas por página
    *   **Rastreo de progreso** con estadísticas detalladas
    *   **Sincronización en la nube** para acceso multiplataforma
*   **Biblioteca integrada** con textos de muestra para práctica

### 🧠 Técnicas de Lectura Optimizadas (2024)

Cada técnica ha sido completamente rediseñada basándose en investigación científica y feedback de usuarios:

#### 🎯 **RSVP Optimizado (Rapid Serial Visual Presentation)**
- **ORP Inteligente**: Punto de fijación morfológico adaptativo
- **Velocidad**: 200-300 WPM en entrenamiento inicial
- **Algoritmo**: Considera sílabas, raíces y longitud de palabras
- **Ideal para**: Eliminación de subvocalización

#### 🔆 **Highlight (Resaltado Completo)**
- **Enfoque**: Palabra completa resaltada con énfasis gradual
- **Velocidad**: 220-600 WPM para expansión del campo visual
- **Diferenciación**: Resaltado completo vs punto de fijación
- **Ideal para**: Reconocimiento visual amplio

#### 📦 **Chunking Inteligente (Grupos Semánticos)**
- **Jerarquía Visual**: Primera palabra prominente, otras con opacidades decrecientes
- **Procesamiento**: Grupos basados en significado, no cantidad fija
- **Velocidad**: Adaptable según complejidad del contenido
- **Ideal para**: Comprensión contextual profunda

#### 📏 **Line Focus Mejorado (Línea por Puntos)**
- **Adaptativo**: Diferente comportamiento en móvil vs desktop
- **Puntuación inteligente**: Rompe líneas en puntos naturales
- **Longitud dinámica**: 6-12 palabras según dispositivo
- **Ideal para**: Simulación de lectura natural controlada

#### 🎯 **Paragraph Focus Optimizado (Lectura por Frases)**
- **Zonas de Atención**: Frase actual + preview + contexto completo
- **Sin dependencia visual**: Eliminamos el "seguimiento como gusano"
- **Velocidad**: 250-500 WPM para textos narrativos
- **Ideal para**: Comprensión de contexto amplio

#### 🎯 **Spritz Optimizado (Meta-guide)**
- **ORP Morfológico**: Algoritmo inteligente de puntos de fijación
- **Sin retículas**: Eliminadas las líneas distractivas
- **Alineación natural**: Sin monospace forzado
- **Velocidad**: 450-900 WPM para máxima velocidad
- **Ideal para**: Lectura técnica y velocidad extrema

#### 🧠 **Biónica (Bionic Reading)**
- **Resaltado silábico**: Inicio de palabras enfatizado
- **Mejora cognitiva**: Guía natural del cerebro
- **Accesibilidad**: Especialmente útil para dislexia

#### 👀 **Entrenamiento Sacádico**
- **Movimientos oculares**: Precisión y velocidad en saltos
- **Posiciones aleatorias**: Entrenamiento adaptativo
- **Ideal para**: Desarrollo de movimientos oculares eficientes

#### 👁️ **Previewing (Análisis Predictivo)**
- **Palabras clave**: Identificación automática de términos importantes
- **Análisis de frecuencia**: Algoritmos inteligentes
- **Ideal para**: Lectura estratégica y estudio

#### 🎓 **Cloze (Ejercicios de Memoria)**
- **Retención activa**: Técnica de completar espacios
- **Memoria de trabajo**: Entrenamiento cognitivo
- **Ideal para**: Mejora de retención y comprensión

## 🚀 **Instalación y Uso**

### **Desarrollo Local**
```bash
# Clona el repositorio
git clone https://github.com/tu-usuario/aLeer-vite.git
cd aLeer-vite

# Instala dependencias
npm install

# Inicia servidor de desarrollo
npm run dev

# Construye para producción
npm run build

# Deploy a GitHub Pages
npm run deploy
```

### **Uso como PWA**
1. **Visita** la aplicación en tu navegador
2. **Instala** haciendo clic en "Instalar App" (disponible en Chrome/Edge)
3. **Disfruta** de funcionalidad completa offline

### **Scripts Disponibles**
```bash
npm run dev          # Servidor de desarrollo
npm run build        # Build de producción
npm run preview      # Vista previa del build
npm run lint         # Análisis de código
npm run deploy       # Deploy a GitHub Pages
npm run test:perf    # Tests de performance
```
